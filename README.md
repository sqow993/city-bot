# caloriePPcounter

Telegram-бот для подсчёта калорий по фото еды.

## Возможности
- Профиль пользователя (вес, рост, возраст, активность)
- Расчёт дневной нормы калорий
- Учёт съеденного за день
- Рекомендации по БЖУ

## Запуск локально
1. Установите зависимости: `pip install -r requirements.txt`
2. Создайте `.env` с `BOT_TOKEN=...`
3. Запустите: `python main.py`
